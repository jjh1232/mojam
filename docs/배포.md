# 배포 — `prelaps.com/mojibake`

> 2026-08-18 이전 완료. 응답 코드는 전부 실측값이다.
> 짝이 되는 문서: `prelaps-home/docs/prelaps-architecture.md`

---

## 1. 구조

Cloudflare **Workers + Static Assets** 다. Pages 가 아니다.

```
브라우저
  ├─ prelaps.com/mojibake/*        →  이 Worker 가 직접 받는다
  │                                    (prelaps-router 를 거치지 않는다)
  └─ mojibake.prelaps.com/*        →  이 Worker 가 받아서 301
```

`prelaps-router` 가 `prelaps.com/*` 를 잡고 있지만 **Cloudflare 는 더 구체적인
라우트를 먼저 쓴다.** `prelaps.com/mojibake/*` 가 더 길어서 이쪽이 이긴다.
그래서 요청이 한 번만 돌고, 공개 주소도 `prelaps.com` 하나뿐이다.

Pages 를 쓰지 않은 이유:

- **Pages 프로젝트는 URL 경로에 못 붙는다.** 도메인 단위로만 붙어서
  `prelaps.com/mojibake` 에 직접 올릴 수 없고, 반드시 앞에 프록시가 필요하다
- **`html_handling` 과 `not_found_handling` 이 Pages 에는 없다.** `.html` 을 떼는
  동작과 404 처리를 설정으로 못 박을 수 없어 호스팅 암묵 동작에 맡기게 된다
- 설정이 대시보드 클릭으로 흩어진다. 여기서는 `wrangler.jsonc` 에 남아 커밋된다

## 2. `src/index.js` — 이 파일이 하는 일

두 가지다.

### 2-1. 경로 접두사 떼기

Workers Assets 에는 "이 경로 아래에 자산을 붙인다" 는 설정이 없다.
자산의 파일 경로가 곧 URL 경로다.

```
prelaps.com/mojibake/styles.css  →  기본 동작은 site/mojibake/styles.css 를 찾는다
                        ↑                  ↑ 이 한 칸이 없다
```

`site/` 를 한 칸 내리는 대신 요청에서 `/mojibake` 를 떼어 `site/` 루트에 맞춘다.
그래서 `site/` 구조도 `test/` 경로도 `npm run serve` 주소도 전부 그대로다.

`assets.run_worker_first` 가 `true` 인 이유가 이것이다. 기본값은 "자산 먼저 찾고
없으면 Worker" 라서, 그대로 두면 접두사를 떼기도 전에 자산 조회가 빗나간다.

**자산 층이 돌려주는 리다이렉트의 Location 에는 접두사를 다시 붙인다.**
안 붙이면 도구 밖으로 튕긴다 — 내부 링크가 `href="index.html"` 이라
홈 버튼 한 번에 터진다.

```
/mojibake/index.html  →  자산 층 Location: /      →  붙이면 /mojibake/
/mojibake/en          →  자산 층 Location: /en/   →  붙이면 /mojibake/en/
```

### 2-2. 구 주소 301

`mojibake.prelaps.com/*` → `prelaps.com/mojibake/*` 로 301.

대시보드 Redirect Rules 를 쓰지 않는 이유는, 커스텀 도메인을 떼면 DNS 레코드까지
사라져서 규칙을 걸 자리가 없어지기 때문이다. 커스텀 도메인을 그대로 두고
Worker 안에서 301 하면 그 문제가 없다.

**이 분기는 안전장치이기도 하다.** 접두사 제거는 경로가 `/mojibake` 로 시작한다고
가정하는데, 구 도메인 요청에는 접두사가 없다. 그대로 흘리면 앞 9글자가 잘려나간다 —
실제로 이렇게 깨졌었다:

```
/styles.css     → slice(9) → "ss"      → 404
/en/            → slice(9) → "" → "/"  → 한국어 루트를 200 으로 서빙 (더 나쁘다)
/content/about  → slice(9) → "about"   → 404
```

색인이 새 주소로 완전히 넘어가면 `wrangler.jsonc` 의 `custom_domain` 줄을 지운다.
그때까지는 남겨둔다.

## 3. 404

`"not_found_handling": "none"` 이면 Cloudflare 기본 404 화면이 나가고 **상태 코드는
제대로 404 다.** 그래도 `site/404.html` 을 두었다 — 방문자에게 브랜드 화면과
돌아갈 길을 주는 편이 낫다.

- `noindex, follow`. canonical·hreflang 은 **넣지 않는다** — 실재하지 않는 주소를
  자기 자신이라고 선언하면 잘못된 신호가 된다
- 주소가 하나뿐이라 언어별로 만들 수 없다. 한국어로 내고 영어·일본어 입구를 함께 준다
- **`test/links.js` 가 이 파일의 존재를 검사한다.** 지우면 테스트가 실패한다.
  15장짜리 언어 격자에는 속하지 않으므로 canonical·hreflang·langsw 검사에서는 빠진다

Pages 로 옮길 일이 생기면 이 파일이 **필수**가 된다. Pages 는 `404.html` 이 없으면
`index.html` 을 status 200 으로 돌려줘서 없는 주소가 전부 정상 페이지로 색인된다.

## 4. 배포

```bash
npm run check:links     # 통과해야 다음으로
npx wrangler deploy     # Node 22 이상
```

배포된 버전 확인:

```bash
npx wrangler deployments list
```

**push 만으로 배포됐다고 믿지 말 것.** 허브(`prelaps-home`)는 Git 연동이 걸려
있는데도 세 커밋이 그냥 넘어갔고 프로덕션이 12시간 전에 멈춰 있었다.
2026-08-18 의 `/ko` 사고가 그것이었다.

## 5. 검증

```bash
for u in /mojibake /mojibake/ /mojibake/index.html \
         /mojibake/en /mojibake/en/ \
         /mojibake/encoding-basics /mojibake/encoding-basics.html \
         /mojibake/content/about /mojibake/styles.css \
         /mojibake/og-image.png /mojibake/sitemap.xml \
         /mojibake/nothing-here /ko; do
  printf '%-38s ' "$u"
  curl -sS -o /dev/null -w '%{http_code} %{redirect_url}\n' "https://prelaps.com$u"
done
```

| 요청 | 기대 |
|---|---|
| `/mojibake` | 301 → `/mojibake/` (prelaps-router 가 처리) |
| `/mojibake/` | 200 |
| `/mojibake/index.html` | 307 → **`/mojibake/`** ← 접두사가 붙어 나와야 한다 |
| `/mojibake/en` | 307 → **`/mojibake/en/`** ← 접두사가 붙어 나와야 한다 |
| `/mojibake/en/` | 200 |
| `/mojibake/encoding-basics` | 200 |
| `/mojibake/encoding-basics.html` | 307 → `/mojibake/encoding-basics` |
| `/mojibake/content/about` | 200 |
| `/mojibake/styles.css` · `og-image.png` · `sitemap.xml` | 200 |
| `/mojibake/nothing-here` | 404 |
| `/ko` | 200 — 허브가 안 죽었는지 |

구 주소도 같이 본다. **하위 경로까지 봐야 한다** — 루트만 보면 위의 slice 버그를 놓친다.

```bash
for u in / /en/ /styles.css /content/about; do
  printf '%-18s ' "$u"
  curl -sS -o /dev/null -w '%{http_code} %{redirect_url}\n' "https://mojibake.prelaps.com$u"
done
```

전부 301 이고 Location 이 `https://prelaps.com/mojibake` + 원래 경로여야 한다.

**브라우저로 세 깊이를 열어볼 것.** 상대 경로는 깊이마다 다르게 풀리므로
한 곳만 보면 놓친다.

```
prelaps.com/mojibake/                  prelaps.com/mojibake/en/
prelaps.com/mojibake/content/about
```
