When reporting a problem

"It did not recover" is the most common report, and it has several possible causes. Sending these two things makes it far quicker to work out which one:

  • The garbled text itself — copy it from the screen and paste it as-is. Sending only the first part turns it into truncated input, which cannot be reproduced.
  • What the original characters were — only if you know.

If the problem came from a file, knowing which program produced the file helps more than the file itself. Please do not send files with sensitive contents — this tool never uploads files to a server in the first place, and they are not needed for a report either.

These are limits of the tool

The cases below cannot be fixed even with a report. The original information is already gone, so no tool can restore it.

  • Characters replaced by ? or � — the bytes themselves were lost.
  • Text copied from a PDF — this is not an encoding problem; the character information inside the PDF is incomplete.
  • Text that passed through messengers or terminals several times — invisible characters may have been dropped along the way. Try copying again from the original.

Before you write

Have a look at the "It did not work" section further down the tool page and find the symptom you are seeing. Most causes of failure are collected there, and about half of them are cases where the information was already gone before the tool received it — those cannot be fixed even if you report them.

Nothing you enter is sent to a server. All processing happens inside your browser and disappears when you close the tab.
