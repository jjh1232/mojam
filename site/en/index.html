What this site commits to

Nothing you enter reaches a server. Pasted text and uploaded files are processed entirely inside your browser. There is no server here that accepts text, so this is not a promise to refrain from sending it — there is nowhere to send it. Close the tab and it is gone, with nothing left on your device either.

No install, no account. Open the page and it works. Nothing to download, nobody to sign up with. Since no work is stored, there is nothing for an account to hold.

Free, with no limits on how often you use it or how much text you pass through it.

Why it all runs in the browser

When text breaks, what people bring along is usually material they never meant to show anyone — an old work file, a forwarded email, a half-finished post. Uploading that to an unfamiliar server to get it fixed creates a second problem on top of the first.

Fortunately this kind of work does not need a server. Reversing an encoding is arithmetic a modern browser handles easily; a 20MB file finishes in milliseconds. Running locally is not a performance sacrifice made for privacy — the server simply was never needed.

You can check for yourself: open the network tab in your browser and use the tool. After the page and its fonts load, no further requests go out.

Nothing you enter is sent to a server. All processing happens inside your browser and disappears when you close the tab.
